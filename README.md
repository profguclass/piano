# piano

**Piano Reader** — open a MusicXML score, see it as sheet music, and play along on an on-screen keyboard or a connected MIDI piano.

**Live:** https://profguclass.github.io/piano/

- **Listen** mode plays the score; **Wait for me** mode highlights the next keys and waits until you play them.
- Practice right hand, left hand, or both; adjust tempo; zoom; repeat a range of bars.
- Connect a USB/Bluetooth MIDI piano with **Connect piano** (Chrome/Edge).
- Opens `.musicxml`, `.xml` and `.mxl` files. Try [`ode-to-joy-sample.musicxml`](ode-to-joy-sample.musicxml).

Everything runs in a single `index.html` with [OpenSheetMusicDisplay](https://github.com/opensheetmusicdisplay/opensheetmusicdisplay) (BSD-3-Clause) bundled inline.
